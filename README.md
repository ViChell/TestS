# Змійка на городі

Браузерна змійка з реєстрацією гравців і спільною таблицею рекордів.
Працює на звичайному PHP-хостингу (PHP 7.4+), без Node.js і без бази даних.

- `public/index.html`: гра, вхід і реєстрація, таблиця рекордів
- `public/api.php`: реєстрація, вхід, збереження рекордів
- `public/data/`: тут сервер сам створить `db.php` з гравцями й рекордами (закрито від браузера)

## Розгортання

Скопіюйте вміст теки `public/` у корінь сайту. Тека `data/` має бути доступна PHP для запису.

## Запуск локально

```bash
cd public && php -S localhost:8000
```
