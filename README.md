# Змійка на городі

Браузерна змійка з реєстрацією гравців і спільною таблицею рекордів.

- `public/index.html`: гра, вхід і реєстрація, таблиця рекордів
- `server.js`: сервер на чистому Node.js (без залежностей), зберігає дані у `data/db.json`

## Запуск локально

```bash
npm start            # http://localhost:3000
```

Змінні середовища:

| Змінна     | За замовчуванням | Що задає                              |
|------------|------------------|---------------------------------------|
| `PORT`     | `3000`           | порт сервера                          |
| `DATA_DIR` | `./data`         | тека, де зберігаються гравці й рекорди |

На хостингу `DATA_DIR` має вказувати на постійний диск, інакше після перезапуску акаунти зникнуть.

## Деплой на patchlab.lga2011.com.ua

Кожен push у `main` (або запуск вручну у вкладці Actions) викладає сайт на хостинг adm.tools через SSH (`.github/workflows/deploy.yml`). Тека `data/` на сервері не чіпається.

Потрібні секрети репозиторію (Settings → Secrets and variables → Actions):

| Секрет               | Що містить                                                        |
|----------------------|-------------------------------------------------------------------|
| `DEPLOY_HOST`        | SSH-хост з розділу «SSH-доступ» в adm.tools                        |
| `DEPLOY_USER`        | SSH-логін                                                         |
| `DEPLOY_SSH_KEY`     | приватний ключ, чий публічний ключ додано в adm.tools → SSH-доступ |
| `DEPLOY_PATH`        | шлях до теки сайту, напр. `/home/<логін>/lga2011.com.ua/patchlab` |
| `DEPLOY_RESTART_CMD` | (необов'язково) команда перезапуску Node.js-застосунку            |
